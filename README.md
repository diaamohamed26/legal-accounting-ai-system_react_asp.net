# ⚖️ Legal Accounting AI System

A full-stack **Legal Accounting Management System** with AI-powered assistance, built with React and ASP.NET Core.

## 🚀 Features

* 🔐 JWT Authentication & Role-Based Authorization
* 👥 Client Management
* 🧾 Invoice Management
* 💰 Expense Management
* 💳 Transactions & Accounts
* 📚 General Ledger
* 📊 Financial Reports
* 📁 Document Management
* 🤖 OpenAI AI Assistant
* 👨‍💼 Admin & Client Dashboards

## 🛠️ Tech Stack

**Frontend**

* React
* Vite
* Tailwind CSS
* Axios
* React Router

**Backend**

* ASP.NET Core
* C#
* .NET 10
* Entity Framework Core
* REST API
* JWT

**Database**

* SQLite

**AI**

* OpenAI API

## ⚙️ Run Locally

### Backend

```bash
cd backend
dotnet restore
dotnet run --urls http://localhost:5001
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend:

```text
http://localhost:5173
```

Backend:

```text
http://localhost:5001
```
